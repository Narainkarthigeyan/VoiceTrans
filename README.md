# VoiceTrans🎤 VoiceTrans – Automated Voice Language Translator
📌 Project Overview
VoiceTrans is a Python-based voice translation application that captures English speech input and translates it into multiple regional languages including Tamil, Hindi, Punjabi, Urdu, and Bengali.
The system integrates speech recognition, machine translation, and text-to-speech technologies to provide both translated text and audio output, enabling seamless multilingual communication.

🎯 Objectives
1. Convert spoken English input into multiple regional languages
2. Provide real-time translated text and audio output
3. Build a user-friendly GUI for smooth interaction
4. Improve translation performance using optimized language datasets
5. Enable accessible communication across language barriers

⚙️ Tech Stack
1. Programming & Interface
2. Python
3. Tkinter (GUI)
4. Speech & Language Processing
5. SpeechRecognition
6. Python Translator
7. Audio Processing
8. pyttsx3 (Text-to-Speech)

🔍 Project Workflow
1️⃣ Voice Input Capture
The application captures English speech input from the microphone using the SpeechRecognition library.

2️⃣ Speech-to-Text Conversion
The spoken input is converted into text using Google Speech Recognition API.

3️⃣ Language Translation
The recognized text is translated into five regional languages using the translation API.

4️⃣ Text-to-Speech Output
The translated text is converted into audio output using a text-to-speech engine.

5️⃣ User Interface
A Tkinter-based GUI provides:
1. Voice input control
2. Language selection
3. Display of translated text
4. Audio playback of translated speech

📈 Key Features
1. Real-time voice-to-text translation
2. Supports 5 regional Indian languages
3. Text and audio output for translated results
4. Simple and responsive GUI interface
5. Improved translation performance by ~20%

🚀 Impact
The application improves multilingual accessibility by enabling real-time speech translation across regional languages, achieving ~20% higher translation efficiency and helping bridge communication gaps for diverse language users.
